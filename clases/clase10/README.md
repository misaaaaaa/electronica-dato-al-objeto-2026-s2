Para hacer una página web estática (tipo portafolio) necesitamos

- una carpeta con todos los archivos necesarios (html y css)
- un hosting (o sitio donde alojarlos), en nuestro caso github pages
- opcional: un dominio (por ejemplo minombre.io). Este es el único paso que tiene costo


para incluir imágenes remotas

## Ejercicio sugerido

Jugar con formas primitivas y texto:

- [arc()](https://processing.org/reference/arc_.html) — Draws an arc in the display window
- [circle()](https://processing.org/reference/circle_.html) — Draws a circle to the screen
- [ellipse()](https://processing.org/reference/ellipse_.html) — Draws an ellipse (oval) in the display window
- [line()](https://processing.org/reference/line_.html) — Draws a line (a direct path between two points) to the screen
- [point()](https://processing.org/reference/point_.html) — Draws a point, a coordinate in space at the dimension of one pixel
- [quad()](https://processing.org/reference/quad_.html) — A quad is a quadrilateral, a four sided polygon
- [rect()](https://processing.org/reference/rect_.html) — Draws a rectangle to the screen
- [square()](https://processing.org/reference/square_.html) — Draws a square to the screen
- [triangle()](https://processing.org/reference/triangle_.html) — A triangle is a plane created by connecting three points
